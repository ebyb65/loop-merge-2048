## Release notes (Play "What's new", plain English)
> Smoother play: tapping a full column no longer ends your game while other columns are free, and running out of lives now takes you back to the menu instead of an empty board. Clearer message when the board is full. Ads no longer count down while you're on the menu. Thanks for playing!

- Last life: goes to "Out of Lives" on the menu, no dead board (d-lastlife)
- Ad timer paused on Out of Lives and the menu (d-adclock)
- Board-full prompt says 'The board is full!'; with the last life the button reads 'End Game (Last Life)' (Lena, 5bee240)
- On-screen debug console hidden in the source (d-debug-off)
- Lives system and timed mid-game interstitial unchanged (CEO decisions 23-24 Nov)
